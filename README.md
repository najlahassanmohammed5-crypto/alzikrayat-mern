# تطبيق الذكريات (Alzikrayat)

مشروع لمقرر تقنيات الويب المتقدمة - جامعة السودان للعلوم والتكنولوجيا.
**إعداد الطالبة:** نجلاء حسن محمد

## فكرة المشروع
تطبيق ويب لمشاركة الصور والذكريات والتعليق عليها، تم تطويره باستخدام تقنيات MERN Stack.

## التقنيات المستخدمة
* **الواجهة الأمامية:** React.js (Vite), Bootstrap 5, Axios
* **الواجهة الخلفية:** Node.js, Express.js, Multer
* **قاعدة البيانات:** MongoDB Atlas (Mongoose)

## خطوات تشغيل المشروع على الجهاز
1. **تشغيل السيرفر:**
   * ادخل إلى مجلد السيرفر: `cd server`
   * ثبّت الحزم المطلوبة: `npm install`
   * أنشئ ملف `.env` وأضف متغير `MONGODB_URI` و `PORT=3000`
   * شغّل السيرفر: `node server.js`

2. **تشغيل الواجهة الأمامية:**
   * افتح نافذة أوامر جديدة وادخل لمجلد الواجهة: `cd client`
   * ثبّت الحزم المطلوبة: `npm install`
   * شغّل التطبيق: `npm run dev`

## الوظائف المتوفرة في التطبيق
* إنشاء حساب جديد وتسجيل الدخول والخروج.
* رفع الصور مع إضافة عنوان ووصف.
* استعراض الصور في المعرض بطريقتين (شبكة أو قائمة).
* فتح تفاصيل الصورة وإضافة تعليقات فورية.
* حذف الصور (متاح لصاحب الصورة فقط).
